# DACQUOISE AMANDE BASE 杏仁达克瓦兹

## Dacquoise Amande 标准版

| Ingrédients | 食材 |
|-------------|------|
| 100 g de blancs d'œufs | 100 克蛋清 |
| 71 g de sucre | 71 克细砂糖（打发用） |
| 71 g de poudre d'amandes | 71 克杏仁粉 |
| 39 g de sucre glace | 39 克糖粉 |
| 25 g de farine | 25 克面粉 |

Monter les blancs avec le sucre, incorporer les poudres tamisées, pocher ou étaler, puis cuire jusqu'à sec et doré.
蛋清加糖打发，折入过筛粉类，挤出或抹平后烤至干爽金黄。
