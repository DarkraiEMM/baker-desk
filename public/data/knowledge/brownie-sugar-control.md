# Brownie 布朗尼减糖与口感控制

## 已验证经验

- 主厨广坦风格布朗尼做过减糖 10%-20%，成品效果不错。
- 这个区间可以作为 Baker Desk 的优先建议：想要不那么甜，先从减 10% 开始；已经熟悉配方时可以试到 20%。
- 不建议第一次就超过 20%，因为糖不只负责甜味，也影响表皮亮度、湿润度、苦味平衡和保质感。

## 判断顺序

1. 先看巧克力和可可粉苦味：黑巧比例越高，减糖越容易显苦。
2. 再看黄油和鸡蛋：油脂和蛋能保湿，但不能完全替代糖的保湿和亮皮作用。
3. 最后看烘烤终点：减糖版更容易显干，中心保留微湿润比烤到全干更稳。

## 推荐调整

| 目标 | 建议 |
|------|------|
| 只是降低甜腻 | 糖先减 10% |
| 已试过原配方，想更清爽 | 糖减 15%-20% |
| 黑巧比例高、可可粉重 | 减糖幅度保守，优先 10%-15% |
| 需要表皮亮、中心软糯 | 不要大幅减糖，优先控制单份大小 |

## 适合搭配

- 核桃、榛子、杏仁等坚果可以增加咀嚼感，分散甜腻。
- 少量酸味水果或咖啡风味能平衡巧克力厚重感。
- 如果目标是早餐或控升糖，布朗尼仍然应该做小份甜点，不应被标成真正低 GI 食物。
